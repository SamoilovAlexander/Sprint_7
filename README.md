# Sprint_7
## итоговый проект по спринту № 7. 
### В ходе проекта были проведены автоматизированные тесты для API приложения ЯндексСамокат. Были выполнены следующие проверки для указанных ручек:

Создание курьера:
- курьер создаётся со всеми обязательными полями
- нельзя создать двух одинаковых курьеров
- нельзя создать курьера, если не заполнено поле Пароль

Авторизация курьера:
- курьер может авторизоваться
- курьер не может авторизоваться, если указан неверный пароль
- курьер не может авторизоваться, если не заполнено поле Пароль
- авторизация не проходит с несуществующими данными(логин, пароль)

Создание заказа:
- заказ создаётся с указанием одного цвета самоката
- заказ создаётся с указанием обоих цветов самоката
- заказ создаётся без указания цвета.
